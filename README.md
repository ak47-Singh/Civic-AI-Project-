# CivicAI – AI-Powered Civic Issue Reporting System

CivicAI is a Generative AI-powered civic issue reporting system designed to make reporting public and civic problems easier through a conversational chatbot.

Instead of filling out a traditional complaint form, users can simply describe their problem in natural language. CivicAI guides the user through the reporting process, identifies the issue category, collects the location and additional details, generates a structured complaint summary, and assigns a priority level.

## 🚀 Features

- 🤖 AI-powered conversational chatbot
- 🏷️ Automatic civic issue categorization
- 📍 Location collection
- 📝 Structured complaint summary
- ⚡ Low / Medium / High priority detection
- 💬 Context-aware conversation flow
- 🛡️ Intelligent rule-based fallback system
- 📊 Complaint dashboard
- ➕ New complaint workflow
- 📱 User-friendly responsive interface

## 🧠 AI Capabilities

CivicAI uses Generative AI to understand natural-language user inputs and provide contextual responses.

The system can handle civic issues such as:

- Roads and potholes
- Garbage and sanitation
- Water supply and leakage
- Electricity issues
- Drainage problems
- Public safety concerns

If the AI service is unavailable, CivicAI uses a rule-based fallback mechanism to continue the conversation instead of completely stopping the reporting process.

## 🔄 How It Works

1. User describes a civic issue.
2. CivicAI identifies the issue category.
3. The chatbot asks for the exact location.
4. User provides additional details or skips them.
5. CivicAI generates a structured complaint summary.
6. The system determines the complaint priority.
7. User confirms the complaint.
8. The complaint workflow is completed and can be viewed through the dashboard interface.
